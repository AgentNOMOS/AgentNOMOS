# AgentNOMOS × NVIDIA OpenShell — S7 execution boundary

Status: **LIVE / VERIFIED**  
Date: **2026-10-03**

This document describes the scoped OpenShell execution-boundary evidence published by AgentNOMOS under **S7 — Execution / Delivery**.

## Responsibility boundary

```text
AgentNOMOS
Intent / Policy / Admission / Authority
        ↓
NVIDIA OpenShell
Runtime / Sandbox / Enforcement
        ↓
AgentNOMOS
Evidence Binding / Receipt / Outcome / Governance
```

The intended reading is precise:

- AgentNOMOS determines whether an action is authorized.
- OpenShell enforces the runtime boundary for the scoped execution lineage.
- AgentNOMOS binds the observed execution into evidence, receipt and outcome.

## Scope

The OpenShell evidence is scoped to:

`openshell_r1_4i_lineage`

The public Trust Chain remains exactly **S0–S10**. OpenShell does not introduce a new top-level stage; it is represented as an `execution_boundary` profile inside **S7 — Execution / Delivery**.

## Design principle

> **Binding != Authorization**  
> **Execution != Semantic Preservation**  
> **Authorized Action != Actual Action**  
> **Signature valid != semantics valid**

AgentNOMOS treats authorization, runtime enforcement, execution evidence and outcome as separate facts that must be joined explicitly rather than inferred from one another.
